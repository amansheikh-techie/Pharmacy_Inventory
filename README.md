# Pharmacy Inventory and Prescription Management System

A web-based database management system (DBMS) project built for managing pharmacy stock, patient prescriptions, doctor records, and medicine sales/billing.

---

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MySQL 8.0
- **Version Control**: Git & GitHub

---

## 📁 Project Structure
```text
Pharmacy_Inventory_PBL/
├── database/          # SQL scripts (Schema definitions and sample data)
├── backend/           # Node.js + Express API server
├── frontend/          # Web interface (HTML, CSS, JS)
├── docs/              # DBMS documentation, ER diagrams, viva notes
├── .gitignore         # Files ignored by Git (keeps passwords safe)
└── README.md          # Project guide
```
